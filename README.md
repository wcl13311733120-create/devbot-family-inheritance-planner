# 跨文化家庭遗产规划助手 (Family Inheritance Planner)

基于 X 热搜 Top 10 推文深度分析（Tweet 3 泰国家庭继承纠纷 1.6M 曝光）开发的 MVP。

## 功能
- 📋 **风险评估**：基于家庭结构（子女数量、遗嘱、赡养协议、跨境资产、债务、保险）计算继承风险评分
- 📄 **法律模板**：遗嘱模板、赡养协议模板、遗产清单模板，一键生成可打印文书
- 📚 **知识库**：泰国家庭继承法、中国继承法、跨境继承、纠纷调解、性别平等、赡养义务
- 📁 **案件管理**：本地存储家庭案件记录，含风险评分

## 技术栈
- Node.js + Express
- 前端：纯 HTML/CSS/JS（无框架）
- 数据：本地 JSON 文件

## 运行
```bash
npm install
npm start
# 访问 http://localhost:3000
```
